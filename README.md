# FX Research Engine v1.5

実データ取得をGitHub Actionsへ移したFX研究エンジン。

- 対象: H4 / D1
- 1万通貨あたりの研究基準: ¥5,000
- 初回取得: 2021-01-01から
- 平日更新: 直近45日を再取得してマージ
- 最大3回リトライ
- CSV重複排除
- SHA-256 / 行数 / 取得期間を provenance に保存
- GitHub Actionsで自動更新

合成データは市場エビデンスとして扱わない。

次段階:
実データ → ¥5,000到達ケース → 特徴量 → 仮説 → バックテスト → 時系列外検証 → 採用/棄却 → シグナル → 実績ログ → 再研究
